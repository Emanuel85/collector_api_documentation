## Endpoint

```http
GET /cards/collector/:id
```

## Descripción

Este endpoint devuelve **todas las cartas** asociadas a un collector específico, incluyendo la rareza aplicada a cada una.

<Info>
  La respuesta expone datos básicos de la carta y su rareza. Para obtener el detalle del template y los slots de atributos, consultar el endpoint correspondiente.
</Info>

## Responsabilidades y alcance

<CardGroup cols={2}>
  <Card title="Qué hace" icon="circle-check">
    Lee y devuelve el listado de cartas del collector referenciado, con su rareza asociada.
  </Card>

  <Card title="Qué NO hace" icon="circle-xmark">
    No modifica ningún recurso. No expone la información del template ni los valores de atributos de cada carta.
  </Card>
</CardGroup>

**Puede modificar:** sin modificaciones (solo lectura).

**Restricciones:** sin restricciones de acceso.

## Parámetros de ruta

<ParamField path="id" type="number" required>
  Identificador único del collector cuyas cartas se quieren consultar.
</ParamField>

## Errores

Todos los errores comparten la misma estructura:

```json
{
  "status": "error",
  "code": "<CODE>",
  "message": "<mensaje>"
}
```

### Recurso inexistente

Origen: PostgreSQL, `ERRCODE P0002`.

<Warning>
  **`NO_DATA_FOUND`** — El collector referenciado no existe.
</Warning>

| `message` | Motivo |
| --- | --- |
| `Collector not found` | El `id` indicado no corresponde a ningún collector existente. |

```json NO_DATA_FOUND
{
  "status": "error",
  "code": "NO_DATA_FOUND",
  "message": "Collector not found"
}
```

## Consideraciones del servicio

<Tip>
  Reglas de negocio, restricciones y decisiones de diseño que aplican al comportamiento de este endpoint.
</Tip>

- **Alcance acotado al collector:** el listado siempre está restringido al collector referenciado. No existe un endpoint para consultar cartas de todos los collectors en simultáneo.
- **Cartas inactivas:** el listado incluye cartas con `is_active: false`. El filtrado por estado, si se requiere, debe realizarse del lado del consumidor.
- **Alcance de datos:** la respuesta expone datos básicos de la carta y su rareza. Los datos del template y los slots de atributos no se incluyen en esta consulta.
